# Care Street · GitHub Pages 배포 파일 (Figma 고해상도 이미지 적용)

## 업로드 방법
1. 이 압축 파일을 다운로드한 뒤 압축을 풉니다.
2. 압축을 푼 폴더 안의 `index.html`, `assets` 폴더, `.nojekyll`을 GitHub 저장소 최상위에 업로드합니다.
3. 기존 파일을 덮어쓰고 Commit changes를 누릅니다.
4. GitHub 저장소의 Settings → Pages에서 `main` / `/(root)`가 선택되어 있는지 확인합니다.

## 이번 버전
- 사용자가 제공한 Figma 추출 이미지 8개를 기존 프로토타입의 대응 화면에 적용했습니다.
- 교체 이미지는 모두 1560 × 3376px이며, JPEG에서 WebP 무손실 방식으로 변환해 픽셀을 추가로 손상시키지 않았습니다.
- 4개 복합질환 홈 화면은 기존 실시간 그래프·복약 횟수 표시가 정상적으로 겹쳐지도록 동적 영역만 비운 템플릿 이미지도 새로 구성했습니다.
- 나머지 이미지, 글꼴, 화면 구성, JavaScript 기능, 터치 영역, 상태 저장 및 화면 이동은 유지했습니다.
- 기존 배포 경로 구조를 유지했습니다. `index.html`과 `assets` 폴더를 함께 업로드해야 합니다.

공개 주소는 현재 저장소의 GitHub Pages 주소를 그대로 사용합니다.
